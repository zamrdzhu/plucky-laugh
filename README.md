## The line

> My smoke alarm only goes off when I am cooking something I am genuinely proud of, like it is jealous of my confidence.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It lands on a cold read: everyone knows a smoke alarm that screams at toast, but this one has taste — it only objects when the cooking is going well. The turn is the last clause, which gives the alarm a motive: jealousy, not safety. A jealous appliance is a funnier villain than a broken one, and the pride-to-punishment flip is the whole joke. One line, 118 characters, well inside the 200-character gate. No setup, no explanation — the alarm's envy is the punchline.
